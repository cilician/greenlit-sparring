# Contributing

- Open an issue first for anything beyond a typo; link it from the pull request (`Fixes #N`).
- One change per pull request; keep the diff small and add a test that fails without the fix.
- Run `npm test` and `npm run lint` before pushing.
- Autonomous tools are welcome to contribute. Say so in the pull request body in one line and name the
  human who is accountable for the change. Undisclosed automated contributions are closed.
